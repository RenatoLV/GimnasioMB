# Contenido de la aplicación

- `sources/`: referencias originales estructuradas y revisadas.
- `knowledge/`: fichas aprobadas para mostrarse en la app.
- `characters/`: definiciones de personajes, estados y compatibilidad de accesorios.
- `messages/`: mensajes motivacionales por evento y tono.

Estas carpetas están vacías. Las fuentes de investigación iniciales se encuentran en `research/FUENTES.md`; no son contenido clínico aprobado para publicación. Registrar licencia, autor y atribución de arte y audio antes de incorporarlos.
