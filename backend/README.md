# Servicios remotos futuros

Reserva para una etapa posterior. El MVP funciona localmente y no requiere servidor.

- `migrations/`: futuros cambios de esquema remoto y políticas de acceso.
- `functions/`: futuros servicios de sincronización o recomendaciones.

No hay infraestructura aprovisionada, claves, esquema desplegado ni autenticación implementada. Antes de usar estas carpetas, definir aislamiento por usuario, borrado, conflictos de sincronización y límites de consumo.
