# Validación futura

Estructura reservada: todavía no hay pruebas ejecutables.

- `unit/`: conversiones, metas, totales y PB.
- `integration/`: persistencia, versiones históricas, copias y futura sincronización.
- `e2e/`: recorridos completos en dispositivo.
- `fixtures/ocr/`: etiquetas de prueba anonimizadas y transcripciones de referencia.

Los resultados esperados iniciales están en [Nutrición y OCR](../docs/NUTRICION_Y_OCR.md) y la cobertura prevista en [Roadmap](../docs/ROADMAP.md). No incorporar datos personales reales a fixtures o capturas del repositorio.
